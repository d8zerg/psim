PsimWatchdog

Контроль работы канала наблюдаемости.

Диагностика

Проверить регулярное получение уведомления внешним мониторингом.

  1. Открыть связанный дашборд, сохранить интервал и выбрать узел или сервис из алерта.
  2. Проверить актуальность сбора, доступность реплик и последние ошибки. Сопоставить с изменениями конфигурации.
  3. На узле выполнить docker compose -f /var/lib/psim-platform/config/<node>/compose.json ps.
  4. Для контейнера проверить docker compose -f /var/lib/psim-platform/config/<node>/compose.json logs --tail=100 <service>; для нативного сервиса - systemctl status psim-<service>.

Восстановление

Отсутствие контрольного уведомления требует проверки Prometheus, Alertmanager, агента и узла наблюдаемости.

Подтверждение результата

Проверка компонента успешна; серия метрик обновляется; алерт перешёл в resolved после полного окна вычисления. Проверить зависимые очереди и функциональную операцию.

Если состояние не восстановлено, сохранить диагностические данные без секретов и передать ответственному за подсистему. Не отключать алерт вместо устранения причины.
