# Коннекторы

Connector SDK (`sdk/`), тестовый набор соответствия протоколу (`conformance/`), симулятор и генератор нагрузки (`simulator/`), эталонный коннектор. Шаги 4.1 и 4.3, протокол - ADR-017.

`simulator/` содержит минимальный настоящий gRPC-клиент [стенда M1](../docs/engineering/event-flow.md). Локальный буфер и полный SDK относятся к шагу 4.1; `libs/sim` остаётся отдельным ручным модельным стендом.
