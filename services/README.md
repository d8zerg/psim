# Сервисы

Один каталог на сервис платформы (ADR-001): `application`, `adapters`, `main`. Сервис зависит от своего доменного ядра из `libs/domain`, от `libs/platform` и от сгенерированных контрактов (`psim::contracts`), но не от других сервисов. Каркас сервиса появляется на шаге 2.1, первые сервисы - на шаге 3.1.
