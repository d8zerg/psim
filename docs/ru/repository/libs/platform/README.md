# Библиотеки платформы

<!-- language-links -->
[English](../../../../../libs/platform/README.md) | [Русский](README.md)
<!-- /language-links -->

Общие механизмы сервисов по ADR-001. Доменное ядро использует собственные порты и не зависит от этих инфраструктурных библиотек.

- `core`: сведения о сборке.
- `errors`, `log`, `config`, `observability`, `runtime`: ошибки, структурированные логи, конфигурация, метрики, трассировка и жизненный цикл сервиса.
- `async`: шарды, часы, дедлайны и противодавление.
- `kafka`: продюсер, потребитель, транзакционный обработчик, сериализация и Schema Registry.
- [`pg`](pg/README.md): libpq, пул соединений, транзакции, миграции, шаблон единицы работы, inbox/outbox и реле.
- `timers`: сохраняемые сроки в схеме сервиса, опрос и атомарное срабатывание с изменением агрегата и outbox (ADR-012).
- [`redis`](redis/README.md): Boost.Redis, RESP3, Sentinel, пул, сериализация, кэш, лимиты, сессии и уведомления.
- [`security`](security/README.md): TLS/mTLS, JWT/JWKS, секреты, CSR и отзыв активных сессий.

- [`clickhouse`](clickhouse/README.md): нативный TLS-клиент, пул, ограниченные запросы, журналируемые пакеты Kafka и миграции.

- [`s3`](s3/README.md): AWS SDK, SeaweedFS, ограниченные файловые потоки, SHA-256, условные записи и безопасные повторы.

- `stream`: общая инфраструктура [сквозного потока](../../../engineering/event-flow.md), исполнение Kafka-обработчиков, сериализация и идентификаторы.

Слои платформенного ядра реализованы. [Симуляционный стенд](../sim/README.md) - отдельная библиотека с ручными задачами `sim:*`. Ограничения и неподтверждённые условия - в [готовности выпуска](../../../product/release-readiness.md).

- `connector`: [C++ SDK коннектора](../../../engineering/connector-sdk.md), дисковый буфер, mTLS, управление потоком, команды и сверка состояния.

`identity` предоставляет read-only каталог учётных записей Keycloak: активность, роли, тенант и области доступа. Incident Service, Response Engine и Notification Service используют один адаптер для проверки получателей и ответственных.
