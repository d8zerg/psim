# ADR-065. Загрузка и бюджеты интерфейса

- **Статус:** Принято
- **Связанные:** [ADR-037](0037-web-monorepo.md), [ADR-062](0062-design-system-and-stable-updates.md)
- **Дополнение:** [ADR-069](0069-application-shell-and-session-recovery.md) - общая поставка рабочей оболочки и витрины
- **Дополнение:** [ADR-070](0070-lazy-loading-and-delivery-budgets.md) - варианты ленивой загрузки и сравнение перед изменением бюджетов

## Решение

Начальная загрузка рабочей консоли сохраняет ограничение 150 КБ JS gzip. Интерактивная витрина, каталог компонентов, сложные виджеты, словари другого языка и ассистент загружаются отдельными точками входа. Каталог разработчика не входит в поставку рабочей консоли.

Суммарный бюджет расширенной витрины - 260 КБ JS gzip. До сложных виджетов сборка занимала 189,17 КБ; с виртуализированной таблицей, перемоткой, диалогами, палитрой команд, источниками значений и оперативным симулятором - 237,98 КБ. Разница 48,81 КБ объясняется этими точками входа и их зависимостями. Лимит оставляет около 9% запаса; каталог с RHF/Zod, дополнительными меню и формами разработчика собирается отдельно. Начальная загрузка рабочей консоли составляет 146170 байт для en и 147071 байт для ru, включая выбранный продуктовый словарь. Она сохраняет предел 150000 байт; остальные словари и оперативный симулятор не входят в начальный граф загрузки.

CSS ограничен 15 КБ; измерено 11,17 КБ gzip. Четыре локальных подмножества WOFF2 занимают 134564 байта и ограничены 150000 байтами. Изменение лимитов требует размеров и причины; повышение порога для скрытия необъяснённой регрессии не допускается.

Проверки размера компонента используют отдельную сборку импорта с внешними React/ReactDOM и без тестового окружения. Учитываются статические зависимости компонента; CSS и шрифты измеряются отдельно. Начальная консоль измеряется с React, транзитивными статическими imports, обычными script из HTML и выбранным продуктовым словарём. Проверяются ru и en отдельно; ленивый импорт выбранного языка не исключает его из начального бюджета. Неиспользуемые entry points должны удаляться сборщиком; `sideEffects` перечисляет CSS.

## Проверка

Манифест начальной загрузки, gzip всех поставляемых файлов, отдельные компонентные сборки и отрицательный прогон с искусственно низким лимитом. Протокол сравнения сохраняет исходные и новые результаты. Размеры публикуются вместе с результатами проверки.
